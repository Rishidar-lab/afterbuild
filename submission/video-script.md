# Suggested video narration (≈115s)

> This is a **suggested** script to make recording easy. Say it in your own words — it's your
> project. Keep it under 3 minutes; ~115s is ideal.

**0–10s — problem**
"When you build with an AI agent, you often get working code faster than you can understand
it. You have the diff — but do you really know what changed?"

**10–25s — input**
"This is Afterbuild. I'll load a sample diff — the kind of change an agent hands you. It's a
real multi-file diff, a TypeScript route and a Python script."

**25–40s — analyze / change map**
"I press Analyze. Instantly I get an aftermath brief: what changed, per file, and a concept
inventory — the technologies and patterns this diff introduced."

**40–75s — the wow: traceability**
"Here's the part that matters. Every concept points at a real line. I click this citation —
and it jumps to and highlights the exact line in the diff. New dependency, an async route,
an auth-token check — each one grounded in the actual code. Nothing is invented; if it isn't
in your diff, Afterbuild doesn't claim it."

**75–100s — learning path + quiz**
"It orders what to understand, and it generates a short quiz from *your* change — each
question cites the line it came from. So I can check that I actually get it."

**100–115s — privacy + close**
"All of this runs in the browser — no API key, no account, nothing leaves the page. AI helps
you ship code faster. Afterbuild helps you understand what you shipped."
