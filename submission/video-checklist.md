# Video checklist

## Before recording
- [ ] `npm run dev` running; http://localhost:5173 open (or the live demo URL)
- [ ] Input empty (press **Clear**)
- [ ] Clean browser window, no personal tabs/secrets visible, ~125% zoom
- [ ] (Optional) Wi-Fi off, to show it runs offline

## Must appear on screen
- [ ] Load sample diff → real multi-file diff visible
- [ ] Analyze → four-section brief (What Changed, Concept Inventory, What to Understand, Quiz)
- [ ] **Citation click → exact diff line highlights** (the wow beat)
- [ ] Quiz **Show answer** with a `file:line` source

## After recording
- [ ] Length ≤ 3:00 (aim ~115s)
- [ ] Uploaded to YouTube/Vimeo, **public/anyone-with-link**
- [ ] Plays in a private browser window with no login
- [ ] URL saved in `submission/devpost-submission.md`
- [ ] No secrets / private repos / personal info anywhere in the frame
